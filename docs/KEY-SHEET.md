# Key sheet for testing levels 5–10

Keys are normally re-hidden at random every run. Each test link below uses **seed 1**, so the layout is
always the one listed here. Open the link and it jumps straight into the level (no need to unlock it on the map).

Directions are as seen from the starting camera: the back wall faces you, the left wall is on your left.
"Left/right door" comes from the joint names in the Lux3D model. If that door is empty, try the other one.

- **Floorboard:** the loose board near the front-left of the floor. Tap it and it lifts.
- **Picture:** the framed picture on the left wall. Tap it and it swings out.
- **Padlocked:** find the small brass key first, then the padlock comes off.
- **Mimic:** it snaps shut and adds 5 seconds. There's nothing in it.

Layouts were read from the real game (`tools/key_sheet.mjs` regenerates them). If the code that places
keys changes, these layouts change too.
