# For judges and automated reviewers

Every claim Rummage makes, where it lives in the code, the test that checks it, and the command that shows it. Commands run from a fresh clone.

## One command for the live claims

```bash
node scripts/check-live.mjs
```

Node 20+, nothing to install, no account, no money. It reads the live site (https://rummage-game.vercel.app) and the ModelScope Studio, and prints pass or fail for each claim. Expected last line: `8 of 8 passed.` Last run: [evidence/check-live-2026-11-18.txt](evidence/check-live-2026-11-18.txt).

## What's live and where

- **Game:** https://rummage-game.vercel.app (Vercel, static) and https://www.modelscope.ai/studios/heisemma/rummage (ModelScope static Studio). Same build, deployed by `tools/deploy_vercel.sh` and `tools/deploy_modelscope.sh`.
- **Lux3D:** called only at build time from `tools/`. The shipped models are in `app/public/models/` and `app/public/props/`.
- **Not live:** generating new furniture in the browser (by design, see README limits).
